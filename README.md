# NMT 2026 — Interactive Data Analysis Dashboard

## About the Project

This project is an interactive dashboard for exploring **NMT 2026 (National Multi-Subject Test) results in Ukraine**.

The goal is to make a large and complex educational dataset easier to understand by turning raw exam results into clear visualizations and interactive analytical insights. Education data can reveal important patterns in students' performance and help better understand differences between regions, subjects, and participant groups.

## Dataset

The analysis is based on anonymized **NMT 2026 open data** published by the Ukrainian Center for Educational Quality Assessment.

The dataset contains information about participants' results across different subjects, as well as demographic and regional characteristics.

## Features

The dashboard allows users to:

* explore overall NMT performance
* analyze score distributions
* compare results across subjects
* examine differences between regions
* filter participants by gender and participant type
* investigate patterns in individual subjects
* interactively explore the data through visualizations

## Technologies

* Python
* Pandas
* DuckDB
* Plotly
* Streamlit

## Project Goal

The main goal is to transform open NMT data into an accessible analytical tool that makes educational statistics easier to explore and helps users discover meaningful patterns in students' performance.

## Data Source

Ukrainian Center for Educational Quality Assessment — NMT 2026 Open Data.
